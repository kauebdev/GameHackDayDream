# GameHackDayDream

About
Em um mundo consumido pelo Vazio, um felino com uma cauda afiada e uma joia mística se ergue. Sua missão é salvar sua dona e o mundo, lutando para absorver a essência das Coleiras de inimigos derrotados e fortalecer-se. Com sua joia, ele busca o Guardião do Vazio, pronto para sacrificar tudo para acabar com a infecção e restaurar a esperança
